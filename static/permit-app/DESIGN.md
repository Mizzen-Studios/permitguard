# Connected isolation clipboard

Retain the equipment-sheet / personal-lock-rail language, not a generic dashboard. Clipboard blue #204c75, paper #f7fafc, ink #183246, rule #bdcbd5, caution #f2bd51 and stop #a42d3b. Local Trebuchet/Segoe sans, large tablet touch targets, left-aligned instructions and sequential step spine. One primary transition; evidence actions secondary. Colour always accompanied by text.

Review: this is a connected version of the existing industrial clipboard, deliberately not the black/neon factory dashboard or a repeating SaaS card kit. No client model, local permit persistence, synthetic principal selection, external fonts or runtime requests. Forge resolver owns identity, revisions and decisions.

Realtime API reference (checked 2026-11-19): https://developer.atlassian.com/platform/forge/apis-reference/ui-api-bridge/realtime/ — scoped realtime.subscribe(channel, callback) returns subscription.unsubscribe(). Use resolver-advertised channel or module-scoped permitguard channel; events only invalidate reads. Never use global channel or trust event payload as authoritative state.

OSHA official reference (HTTP 200 checked 2026-11-19): https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.147 . Onscreen mapping is informational, not a compliance assessment.

Owner skipped live browser, physical camera/QR, Rovo Studio and two-browser Realtime acceptance. Build/static tests are not proof of those capabilities.
